# Rakib Hossen — Video Editor Portfolio
React + Vite + Tailwind + Framer Motion + GSAP.

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist

Edit content in `src/data/`: personalInfo.js (contact, socials, stats, photo), projects.js (add projects), skills.js, services.js.
Google Drive previews only work if each file is shared as "Anyone with the link".
